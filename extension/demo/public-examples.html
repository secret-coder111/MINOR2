When the examiner asks for a web demonstration

Let them choose. Record what actually happens.

  1. Start with a legitimate login page chosen by the examiner. Enter no credentials; inspect PhishGuard's actual result.
  2. Use the independent BadSSL page to test an HTTP credential prompt. It is an intentional security fixture, not a criminal phishing incident.
  3. Use AMTSO or Google's test to demonstrate browser/vendor protection separately. Stop at a browser block; do not bypass it or credit it to PhishGuard.
  4. Return to the controlled visual pages, change one actual title or destination, and show the extension rescanning. A hosted copy is still a controlled fixture, not an independent accuracy benchmark.

Present honestly: “These tests demonstrate observed behavior. Measuring missed phishing and false alarms requires an independent unseen dataset.”
